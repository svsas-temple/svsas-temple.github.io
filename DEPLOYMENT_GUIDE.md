# 🚀 Zero-Cost ($0/Month) Hosting & Deployment Guide
**Sri Vinayaka Subramanya Ayyappa Swamy Devasthanam Website**

This website is engineered as an ultra-fast, zero-dependency, lightweight web application. It requires **zero backend servers**, has **zero database maintenance costs**, and runs on the world's most generous free tiers permanently.

---

## Option 1: Deploy with Vercel (Recommended - Fastest & Easiest)
**Cost: $0.00 / month forever**

1. **Push your code to GitHub:**
   - Create a free account at [github.com](https://github.com).
   - Create a repository (e.g. `temple-website`) and push all project files.

2. **Connect to Vercel:**
   - Go to [vercel.com](https://vercel.com) and sign up with your GitHub account.
   - Click **"Add New..."** -> **"Project"**.
   - Select your `temple-website` repository.
   - Leave all default settings (Framework: Other) and click **"Deploy"**.
   - In 15 seconds, your website is live worldwide on a secure `https://your-temple.vercel.app` URL with automated global CDN!

3. **Connect Your Custom Domain:**
   - In your Vercel Project Dashboard, go to **Settings** -> **Domains**.
   - Type your custom domain (e.g., `ayyappanacharam.org`).
   - Add the two DNS records (CNAME and A record) shown by Vercel into your domain provider (e.g., GoDaddy, Namecheap, or Cloudflare).
   - Vercel automatically generates and renews your **free SSL certificate** forever!

## Option 2: Deploy with Cloudflare Pages
**Cost: $0.00 / month forever with unlimited bandwidth**

1. Go to [dash.cloudflare.com](https://dash.cloudflare.com) and sign up for free.
2. Under **Workers & Pages**, click **"Create application"** -> **"Pages"** -> **"Connect to Git"**.
3. Select your repository.
4. Build settings:
   - Framework preset: `None`
   - Build output directory: `/` (root)
5. Click **"Save and Deploy"**.
6. Cloudflare gives you unmetered DDoS mitigation, lightning-fast edge servers in Hyderabad and across India, and free SSL.

---

## Option 3: Deploy with GitHub Pages
**Cost: $0.00 / month forever**

1. In your GitHub repository, go to **Settings** -> **Pages**.
2. Under **Build and deployment**, set **Source** to `Deploy from a branch`.
3. Select branch: `main` and folder `/ (root)`.
4. Click **Save**. Within 1–2 minutes, your website is live at `https://<username>.github.io/<repo-name>/`.
5. You can also add your custom domain under the "Custom domain" section.
