## 🌟 Key Features
* **100% Free Lifetime Hosting ($0/Month Forever):** Engineered with zero backend server requirements. Can be deployed to Vercel, Cloudflare Pages, or GitHub Pages in under 2 minutes with free global CDN and automatic SSL.
* **0% Transaction Fee Bharat UPI Donations:** Direct transfer straight into the temple's **Punjab National Bank Account** (`1582102100001322`, IFSC: `PUNB0158210`). No intermediary fees or payment gateway cuts.
* **Instant Bilingual Switcher:** Complete one-click toggle between English and Telugu (`తెలుగు`) with zero page reloads.
* **Interactive Features:**
  - One-click copy for Account Number, IFSC Code, and Temple Address with toast confirmations.
  - Dynamic QR code generation for preset donation amounts (₹101, ₹501, ₹1,116, ₹2,500, ₹5,116) or custom sums.
  - Direct UPI app launch on mobile devices (Google Pay, PhonePe, Paytm, BHIM).
  - Devotee receipt submission formatted directly for WhatsApp.
  - Lightbox modal for zooming into high-res deity shrines and the official signed fundraising circular from Chairman Sri C.S. Mallesh.
  - Live Google Maps embed centered on the temple's coordinates with step-by-step public transit guidance.
* **Rich Sacred Aesthetics:** Designed using auspicious temple colors (saffron gold, vermilion red, sandalwood cream, brass deepam glow) and elegant typography (`Cinzel`, `Plus Jakarta Sans`, `Noto Sans Telugu`).

## 🚀 How to Run Locally
Simply open `index.html` in any modern web browser (Chrome, Edge, Safari, Firefox). No build tools, Node.js, or complex installations required!

Alternatively, you can run a local test server using Python:
```bash
python -m http.server 8000
```
Then navigate to `http://localhost:8000`.
